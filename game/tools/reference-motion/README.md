# Перенос движения из пользовательского видео

`measure.py` работает из корня проекта. Вход — все декодированные исходные
кадры первых 5,5 с (без изменения fps), `.cache/reference-frames/0001.png` и далее (либо задайте `--frames`).
Выбран полный шаг на кадрах 19–46. В `measured-frames.csv` сохранены координаты
в исходном изображении 480×216. Столбец bag_x нужен для компенсации камеры.
Положения коленей по высоте размечены по увеличенным кадрам; центры силуэта
измеряются по строкам изображения. Сглаживание 0,65 исходного кадра подавляет
пиксельный шум, небольшая коррекция на всём цикле замыкает его конец.

`ReferenceSamples.java` — данные переноса, `ReferenceMotion.java` — риг и
сэмплирование. `ReferenceSilhouette.java` — контуры туловища и штанин из фото,
нормализованного до 1504×1694, 6,8 пикселя на единицу арены. Указаны узлы
обводки и опорные кости, так что профиль можно воспроизвести и уточнить.

Это реконструкция видимой 2D-проекции, а не исходные игровые анимационные данные.
Скорость и длина шага согласованы в игре; JSON хранит перспективные длины
костей, темп и путь за цикл. Пользовательские удары остаются в прежнем риге.
