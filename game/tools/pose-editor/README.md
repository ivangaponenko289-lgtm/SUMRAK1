# Редактор анимаций

Запуск из корня проекта: `Animation-Editor.cmd`.
Сборка: `python tools/pose-editor/build.py --smoke`.
Готовый редактор: `dist/AnimationEditor.jar`.

Выберите ходьбу или удар сверху, кадр — на нижней шкале. Перетаскивайте суставы
либо меняйте углы справа. Правка промежуточного кадра создаёт ключ автоматически.
Ползунок «Темп» сохраняет скорость от 0,25× до 2× вместе с JSON.

«Применить к игре» записывает выбранную анимацию в `assets/animations`.
Версия на ПК читает её из этой же папки при запуске. «Проверить в игре» открывает
`dist/Sumrak-desktop.jar`. Для переноса изменений на телефон пересоберите APK.

Файлы проекта находятся поиском `AndroidManifest.xml` вверх от расположения JAR:
редактор не зависит от старой папки `gh/outputs`.
Временные результаты проверок сохраняются только в `.cache/reports/editor`.
