# Сумрак — рабочий проект

Это актуальный рабочий каталог игры и редактора (версия 0.31).
Старые версии сборок, резервные копии и изображения проверок сюда не перенесены.

## Запуск

- `Game.cmd` — игра на ПК.
- `Animation-Editor.cmd` — редактор анимаций.
- `Build.cmd` — пересобрать игру, APK и редактор, выполнить проверки.

В `dist` лежит только текущая сборка: `Sumrak-desktop.jar`, `Sumrak.apk`,
`AnimationEditor.jar`. При сборке эти файлы обновляются. Перед пересборкой
закройте игру и редактор, чтобы Windows не блокировала JAR-файлы.

## Главные папки

| Папка | Что здесь менять |
|---|---|
| `src/ru/shadowduel` | Общая логика игры, персонажи, скелет, анимации, управление и Android-код |
| `assets/animations` | Актуальные анимации JSON, включая пользовательский удар ногой |
| `assets/audio`, `assets/backgrounds` | Звуки, музыка и фон арены |
| `tools/pose-editor/src` | Интерфейс и логика редактора анимаций |
| `desktop/ru/shadowduel` | Запуск, графика и звук версии для ПК |
| `res` | Иконки и системные ресурсы Android |
| `tests` | Автоматические проверки; `fixtures` — два необходимых образца для проверки удара |
| `tools/reference-motion` | Измерения видео и генератор контура/движения персонажа |
| `audio` | Скрипты генерации звуков и импорта музыки |
| `desktop-assets` | Музыка в WAV для версии на ПК; Android использует MP3 из `assets` |
| `docs` | Описание формата анимаций |
| `dist` | Готовые приложения, исходники здесь не редактировать |

Редактор сохраняет «Применить к игре» прямо в `assets/animations`.
Игра на ПК читает эти же файлы: отдельной копии анимаций рядом с JAR нет.
После изменения перезапустите игру. Для Android пересоберите APK.
Самостоятельно перенесённый JAR использует упакованные в него анимации.

## Сборка и окружение

Нужны Python 3, JDK 17 и Android SDK. На этом компьютере пути уже указаны
в `toolchain.local.json`: инструменты используются из `../gh/work/tools`.
Этот каталог пока нужен для запуска и сборки; инструменты не дублировались.
При переносе на другой ПК исправьте пути или передайте параметры явно:

```text
python build.py --jdk PATH --build-tools PATH --android-jar PATH
python tools/pose-editor/build.py --jdk PATH --smoke
```

`.local/signing.p12` — действующий локальный ключ подписи APK, сохранённый
для совместимости обновлений. Не удаляйте его и не публикуйте вместе с исходниками.
`.cache` — временные файлы сборки и отчёты; создаются автоматически, их можно
удалить после завершения сборки. Эти каталоги, сборки и локальные настройки
исключены из Git через `.gitignore`.

Код, JSON, медиа и настройки редактора перенесены из
`../gh/outputs/ShadowDuel`. Актуальные анимации совпадают с прежними побайтно.
Старый каталог оставлен на месте. Для дальнейшей работы открывайте эту папку.
